# 操作与验收

## 连接

连接摄像头、HDMI 显示器和电源。使用数码管时将板上 SW6 置 DIG；蜂鸣器声音由板上 SW5 接通。使用按键时以板上 KEY1～KEY4 为准。

## 按键和开关

| 控件 | 功能 |
|---|---|
| KEY1 | 切换饮料、红色动态、图像算法三组 |
| KEY2 | 选择菜单、饮料类别或图像算法 |
| KEY3 | 确认、采集下一张样本或发起识别；图像组中切换强度 |
| KEY4 | 返回或取消未提交的录入 |
| SW1 | 保留 |
| SW2 | 详细信息显示 |
| SW3 | 屏幕 AUTO=1 为自动曝光；AUTO=0 请求保持曝光 |
| SW4 | 屏幕 WRITE=1 允许修改样本；WRITE=0 写保护 |
| SW5 | 板上蜂鸣器硬件使能 |
| SW6 | DIG 使能数码管复用 |

拨码的机械方向以屏幕显示的 AUTO/WRITE 数值为准。曝光保持会等待已经发出的相机写入完成。

## 录样和识别

固定背景、照明和摄像头。自动曝光稳定后保持曝光，通过饮料菜单执行白平衡维护；放入白纸并按确认，成功后取走白纸。进入背景录入页，空场保持稳定后按 KEY3。

进入样本库，KEY2 选择类别，KEY3 进入录入页。瓶子正立、标签朝前放入摆放框，依次按 KEY3 采集正面、略向左转约 5°、略向右转约 5°三个视角，等待每次采样完成。录满三张后类别生效；KEY4 可取消未提交的录入。其他类别按同样步骤录入。

返回实时页，放入饮料并按 KEY3 发起识别。成功后显示名称、匹配分与状态，并发出短提示。拿走饮料后观察空场恢复。单类可独立重录；背景也可独立更新。白平衡重新成功校准后，需要重新录入背景和样本。

样本存在 RAM 中。断电或 R10 硬复位后重新录入。固定工位和补光有利于保持录样与识别条件一致。

## 辅助展示

红色动态组的 X/Y 为红色目标中心，MX/MY 为运动区域包围框中心；无对应目标时显示 0000。数码管优先显示红色坐标，其次显示运动坐标。

图像算法组用 KEY2 切换 ORIGINAL、GRAY、SOBEL、CARTOON、MEDIAN、CLHE、BINARY。KEY3 切换 LEVEL 1 细节、LEVEL 2 标准、LEVEL 3 降噪，默认 LEVEL 2。强度作用于边缘和二值化。所有字幕透明叠加，保留安路与赛事标识。

## 下载与启动

选择 bitstream/drink_vision.bit。先用 SRAM 下载检查画面和操作；需要独立上电启动时，在 BitWriter 选择配置 Flash 的 PROGRAM_FLASH，按实际芯片容量设置（本板已确认配置 Flash 为 128 Mbits），完成后使用 VERIFY_FLASH 校验，再断电重启验证。程序固化不代表 RAM 样本被保存。
