# 系统设计

## 硬件链路

HX1P35A 开发板采用 PH1P35MDG324 FPGA。摄像头通过 MIPI 输入视频，经接收、RAW 数据处理、白平衡与缓存后进入显示处理链路，最终通过 HDMI 输出。有效画面尺寸为 1280×720。

## 饮料识别

使用固定摆放区域与标签特征区域，采用降噪 RGB 的分区颜色统计，以及 24×48 灰度缩略图的八邻域局部结构编码。匹配器串行复用距离运算，对三个视角模板及九种平移位置进行搜索，联合结构和颜色距离进行拒绝判定。按 KEY3 发起识别，对不同采集编号的帧进行投票，八帧中至少六帧支持同类才确认。匹配分表示模板相似程度，不等于准确率。

每类录入三个视角，每张由八个不同采集帧平均得到。采样前检查稳定性、亮度、反光和有效结构；三张完整提交后类别才启用。重录单类不改变其他类别与背景，取消未完成采样时保留已提交样本。白平衡成功重校准会使颜色样本和背景失效。

## 图像处理

提供原图、灰度、Sobel、彩色卡通、灰度中值、限幅直方图均衡和自适应二值化。边缘显示采用中值降噪后 Sobel 阈值判决。二值化使用 5×5 二项式高斯局部亮度、完整帧平均亮度、噪声门控锐化和自适应阈值，输出纯黑白画面；局部与帧亮度参考权重为 75%/25%。KEY3 在图像组内切换三档强度。

## 红色动态识别与交互

红色目标采用颜色条件、连通行段、区域跟踪和时间稳定判定，显示包围框、中心坐标与十字。运动检测在采样网格上进行帧间亮度比较，显示运动区域及中心坐标。仅该功能组显示红色和运动框及对应告警。

四颗按键和拨码先同步、消抖，页面动作在帧边界生效。数码管与 LED 状态通过一致性握手传递到外设时钟域；蜂鸣提示采用事件去重。数码管段选和位选低有效，扫描时设置位间消隐。

## 时序与存储

饮料和红色组的 HDMI 输出为七拍流水线；图像算法组为十一拍。视频、有效信号、坐标、同步和标识采用对应延迟；分类输入与采集编号保持四拍对齐。时钟与跨域约束位于 td_project/camera_to_dsi_display.sdc。

本工程程序可写入配置 Flash。样本、背景和校准状态运行于 RAM，不包含样本断电保存服务。厂商 IP 及其版权声明随完整源码保留。
